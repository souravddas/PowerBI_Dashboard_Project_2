# PowerBI_Dashboard_Project_2
HR Analytics Dashboard 📈

This Power BI dashboard provides a comprehensive analysis of employee attrition trends using the HR_Analytics.csv dataset.
It identifies key factors influencing turnover across job roles, age groups, salary slabs, and education fields.

📊 Dashboard Overview

Total Employees: 1,470

Attrition Rate: 16.1%

Average Age: 37 years

Average Salary: 6.5K

Avg Tenure: 7 years

🔍 Key Insights

Most attrition in the 26–35 age group.

Employees earning below 5K show the highest turnover.

Life Sciences and Medical backgrounds dominate attrition.

Early-career employees (less than 2 years) are most likely to leave.
